# 🩺 AI Medical Report Reader

AI-powered web app that reads medical reports (PDF & Images) and gives a simplified health summary.

## 🚀 Features
- Upload Medical Reports - PDF / Image
- OCR Text Extraction
- AI-Based Analysis & Key Values Extraction
- Simplified Health Summary in Easy Language
- Clean & Responsive UI

## 🛠️ Tech Stack
- Python
- Flask
- OCR (Tesseract / EasyOCR)
- NLP
- HTML / CSS / JavaScript

## 📦 How to Run
```bash
pip install -r requirements.txt
python app.py
